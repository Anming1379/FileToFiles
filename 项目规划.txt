# ALambda File To Files — 产品需求文档（PRD）

版本：v1.0
作者：Anming_cat
平台：Windows 10 1809+ / Windows 11（win-x64，可选 win-arm64）
技术栈：C# / .NET 10 / WPF / MVVM CommunityToolkit

---

## 1. 产品概述

File To Files 是一款基于 FFmpeg 的 Windows 桌面音视频格式转换器。
用户导入一个或多个文件，整批统一选择一个目标格式（如 H.264 MP4、高质量 MP3），
一键批量转换，实时查看进度、状态与输出结果。

核心定位：
- 简单：拖入 → 选格式 → 开始。
- 可控：内置高质量预设，也可自定义编码参数。
- 可靠：进度准确、可取消、失败可定位、输出不产生半成品。

非目标（MVP 不做）：
- 一个输入文件输出多个目标文件
- 时间线剪辑、复杂滤镜链
- DRM 解密、在线视频下载
- 跨平台

## 3. 用户与场景

- 普通用户：把手机拍的 MOV 拖进来，选“高质量 H.264 MP4”，转成通用格式。
- 批量用户：一次导入 50 个 WAV，统一转成高质量 MP3。
- 进阶用户：选择“自定义”，调整 CRF、分辨率、帧率、音频码率，另存为个人预设。
- 排错用户：转换失败时，在输出列表看到可读错误，可复制 FFmpeg 命令。

## 4. 功能需求

### 4.1 主窗口结构

- 顶部：工具栏
- 中部：三个 Tab（输入文件列表 / 转换设置 / 输出文件列表）
- 底部：状态栏

### 4.2 工具栏

按钮与控件（从左到右）：
- 添加文件
- 预设下拉框（显示当前预设，如 “高质量 H.264 MP4”, 如已被修改在前面加*）
- 开始转换/停止
- 设置

规则：
- 目标格式为整批统一，切换后转换设置 Tab 标题同步更新。
- 列表为空时“开始转换”禁用。
- 转换进行中“开始转换”禁用，“停止”启用。
- 预设下拉框与转换设置 Tab 内“容器/编码”联动，二者始终一致。

### 4.3 Tab 1：输入文件列表

列表列：
文件名 | 源容器 | 源视频编码 | 源音频编码 | 时长 | 分辨率 | 大小 | 状态 | 进度

功能：
- 拖放文件或文件夹导入；文件夹递归扫描支持的扩展名。
- 按钮添加文件（多选）/ 添加文件夹。
- 导入后异步 ffprobe 探测，逐条填充媒体信息，状态 Pending → Probing → Ready。
- 右键菜单：移除、打开源目录、查看媒体详情、重新探测。
- 多选支持；按住 Ctrl + 鼠标左键多选, Delete 键移除。
- 底部信息：共 N 个文件 · 总大小 X
- 列表虚拟化，1000 条不卡顿。

状态值：Pending / Probing / Ready / Running / Completed / Failed / Canceled。

### 4.4 Tab 2：转换设置（标题动态显示目标格式）

标题规则：
- 整批统一格式时，标题为格式名，如 “H.264 MP4”、“MP3”。
- 用户切换工具栏目标格式后标题立即更新。

内容分区：

A. 预设区
- 预设下拉框（显示当前预设，如 “高质量 H.264 MP4”）

// 用户先选择一个预设, 后可直接对预设进行自定义修改 (不是修改预设源文件, 修改内容仅本次转换有效)

B. 视频参数（目标为视频格式时显示）
- 目标格式：mp4 / mkv / webm / mov
- 视频编码：libx264 / libx265 / libvpx-vp9 / libsvtav1 / copy
- 质量模式：CRF / 固定码率
- CRF 值（0–51）
- 视频码率（kbps，质量模式为固定码率时可用）
- 分辨率：保持原始 / 1080p / 720p / 480p
- 帧率：保持原始 / 60 / 30 / 25 / 24 / 15
- 像素格式：保持原始, 无需添加

C. 音频参数
- 音频编码：aac / libmp3lame / libopus / flac / pcm_s16le / copy / 无音频
- 码率或质量：如 320k / 192k / V0
- 采样率：保持原始, 无需添加
- 声道：保持原始, 无需添加

D. 高级
- 硬件加速：自动 / 关闭 / NVENC / QSV / AMF（不可用时置灰）

E. 底部操作
- 恢复默认
- 另存为自定义预设（弹出命名对话框，写入用户配置）

规则：
- 参数改动后，当前批次所有 Ready 状态文件的目标参数同步更新。
- 目标为纯音频格式时隐藏视频参数区。
- 参数校验：CRF 0–51，码率正整数，分辨率合法。

### 4.5 Tab 3：输出文件列表

列表列：
输出文件名 | 目标格式 | 大小 | 耗时 | 状态 | 输出路径

功能：
- 转换成功后逐条出现。
- 右键：打开所在目录、播放、重新转换、删除输出文件。
- 顶部显示当前输出目录，可点击打开。
- 失败条目显示错误摘要，双击查看详情与 FFmpeg 命令。

### 4.6 状态栏

从左到右：
- 总体进度条 + “已完成 M / 总数 N”
- 当前转换文件名
- 输出目录（可点击打开）
- FFmpeg 状态：就绪 / 未找到 / 版本不匹配 (以圆形颜色指示灯展示)
- 并发数
- 版本号

### 4.7 设置窗口

- 常规：默认输出目录
- 转换：最大并发数 1-8 默认 2、转换完成后通知、完成后打开输出目录
- FFmpeg：内置路径（只读展示）、自定义路径（可选覆盖）、版本检测按钮
- 外观：主题（浅色 / 深色 / 跟随系统）
- 高级：日志目录、打开配置目录

// 文件名冲突策略直接覆盖, 输出文件命名格式{源文件名}.{目标扩展名}

### 4.8 主题

- 浅色与深色两套完整资源字典。
- 切换即时生效，无需重启。
- “跟随系统”监听系统主题变化。
- 所有自绘控件、列表、进度条、对话框均适配两套主题。

### 4.9 日志与错误

- Serilog 滚动日志，按天分文件，保留 7 天。
- 每条转换记录：源路径、输出路径、完整 FFmpeg 命令、退出码、stderr 摘要、耗时。
- 失败时 UI 显示可读原因（如“输出目录无写入权限”“编码器不支持”）。
- 支持复制 FFmpeg 命令。

## 5. 非功能需求

- 启动到可交互 < 2 秒（冷启动，SSD）。
- 导入 100 个文件后 UI 不阻塞，探测逐条异步完成。
- 进度更新节流 500ms，CPU 占用平稳。
- 点击停止后 3 秒内终止进程并清理临时文件。
- 输出采用临时文件 + 成功后重命名，异常中断不留下半成品。
- 路径支持中文、空格、长路径（启用 longPathAware）。
- 单实例运行，重复启动激活已有窗口。
- 崩溃时写崩溃日志，下次启动提示。

## 7. 验收标准（MVP）

1. 拖入 3 个不同格式视频，选“高质量 H.264 MP4”，全部转换成功，输出可播放。
2. 导入 50 个音频，选“高质量 MP3”，并发 2 下全部完成，状态栏进度正确。
3. 转换中点停止，3 秒内停止，无残留 .part 文件。
4. 输出目录只读时，任务失败并显示可读原因。
5. 切换深色/浅色主题，全部界面即时生效。
6. 1000 条输入列表滚动流畅。
7. 关闭再打开，设置与自定义预设保留。
8. 便携版解压即用；安装包安装后开始菜单可启动、可卸载。
9. 关于页展示版本、作者 Anming_cat、FFmpeg GPL 声明与源码获取方式。
