FFmpeg 对应源码提供承诺（GPLv3 第 6 条）
========================================

本程序（ALambda File To Files）随包分发以下 GPLv3 软件的可执行文件：

    ffmpeg\ffmpeg.exe
    ffmpeg\ffprobe.exe

版本标识：n9.0.2-36-g6882969ce9-20261026
构建日期：2026-10-26
构建来源：gyan.dev 提供的 win64-gpl 构建
构建脚本：https://github.com/GyanD/codexffmpeg

一、对应源码的获取方式
----------------------
1. FFmpeg 主源码
   仓库：https://git.ffmpeg.org/ffmpeg.git
   或镜像：https://github.com/FFmpeg/FFmpeg
   提交：6882969ce9（即版本 n9.0.2 之后 36 个提交）
   获取命令：
       git clone https://git.ffmpeg.org/ffmpeg.git
       git checkout 6882969ce9
   也可下载发行包：https://ffmpeg.org/releases/

2. 构建时启用的 GPL 组件源码
   libx264  : https://code.videolan.org/videolan/x264        （GPL v2+）
   libx265  : https://bitbucket.org/multicoreware/x265_git   （GPL v2+ 或商业授权）
   libxvid  : https://downloads.xvid.com/                    （GPL v2+）

3. 构建配置
   完整 ./configure 参数可通过执行以下命令获得：
       ffmpeg.exe -version
   其中 "configuration:" 一行的内容即为本二进制使用的确切构建参数
   （包含 --enable-gpl --enable-version3 以及全部第三方库开关）。
